# Daylist

A simple everyday todo app. Pick a day, add what needs doing, check things off, and come back tomorrow.

## Features

- **Daily lists** — each day has its own todos
- **Date navigation** — move between days or jump back to today
- **Add, complete, edit, delete** — click a todo to edit it
- **Progress** — see how much of the day is done
- **Carry unfinished tasks** — pull incomplete items from the previous day
- **Local persistence** — saved in your browser via `localStorage`

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Stack

- React 19
- TypeScript
- Vite
